# 🍽️ FreshBite - Online Food Ordering Website

A modern and responsive **Food Ordering Website** built using **HTML5, CSS3, and JavaScript**. FreshBite allows users to browse delicious food items, add products to a shopping cart, manage quantities, and simulate the checkout process with a clean and user-friendly interface.

---

## 📌 Project Overview

FreshBite is a frontend-based food ordering application designed to provide a seamless online food ordering experience. The project focuses on responsive web design, dynamic cart functionality, and an attractive user interface without using any backend or database.

---

## 🚀 Features

- 🍕 Responsive Homepage
- 🍔 Restaurant Listing
- 🍝 Food Menu
- 🛒 Add to Cart
- ➕ Increase / ➖ Decrease Quantity
- 💰 Automatic Total Price Calculation
- 💾 Cart Data Stored using Local Storage
- 📦 Checkout Simulation
- 📱 Fully Responsive Design
- 📩 Contact Form
- 🎨 Modern Black & Gold User Interface
- ⚡ Smooth Scrolling Navigation
- ✨ Hover Animations

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
